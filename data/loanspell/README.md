# Loanword spelling data (V29.3)

- loan-table.tsv: English word -> Bangla spelling, generated by a rule mapper from CMU Pronouncing Dictionary pronunciations (BSD licence, see NOTICE-cmudict.txt). Words on the Bangla word lists are pruned out.
- overrides.tsv: hand-checked spellings that win over the table (voice path only).
- gen_java.py: run from the repo root to regenerate GboardRamblerLoanTable.java and the OVERRIDE block in GboardRamblerLoanSpell.java.
