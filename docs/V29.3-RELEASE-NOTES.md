# V29.3 release notes

Source-only release. This repository distributes no APKs.

## New features

- **Multilingual voice typing, one language per sentence.** On the
  multilingual layout (abc → বাংলা), each dictated sentence is written fully
  in Bangla script or fully in English. Start in either language and switch
  whenever you like.
- **Real Bangla spellings for English words.** English words spoken inside
  Bangla now come out as proper transliterations (কোম্পানি, টেলিভিশন,
  বার্লিন) instead of letter-by-letter output. Transliteration only, never
  translation. Blind check: 85 of 200 exact, up from 17 of 200.
- **Clipboard drag-to-reorder.** In the clipboard panel, long-press an item,
  drag it, and drop it to change the order.
- **Protected text.** #hashtags, @handles, links, emails and times stay in
  Latin letters on every voice path.

## Settings explained

**Bangla script correction** (on by default)
- On: Romanized Bangla becomes Bangla script, English words get the new
  spellings, and each layout follows its own rule (see the README table).
- Off: Rambler converts nothing, for voice or typing. You get Gboard's own
  output, so Bangla speech may stay in Latin letters.
- Turn it off if you prefer Romanized Bangla, or to check whether an odd
  result comes from Rambler or from Gboard.

**Rambler diagnostics** (off by default)
- For bug reports only. Turn it on, repeat the problem, then turn it off.
- Turning it off saves `RamblerBangla-diag-<date>-<time>.txt` to Downloads.
- The log includes the text you dictated or typed, before and after
  conversion. It stays on your phone unless you share it. Leave it off in
  normal use.

## Other changes

- "doctor" is written ডক্টর (transliteration) everywhere.
- Typing and paste conversion are unchanged from V29.

## Tested

- Host test suite: 292-case corpus across all three layouts; all release
  gates pass (`tests/v29.3/`).
- Real device: Bangla-only and English-only layouts confirmed working. The
  multilingual layout was confirmed on a real device, with a few misses in
  quick mid-sentence switches (below).

## Known limits

- Very short Romanized Bangla sentences (three words or fewer, all
  colloquial) can stay in Latin letters.
- A Bangla clause and an English clause spoken as one sentence, with no pause,
  follow the majority language.
- Clipboard drag: the live reorder can swing too far sideways while an item
  is held. Smoother motion is planned.
- Gboard's combined "EN · BN" keyboard reports itself as English (US), so
  Bangla spoken there stays in Latin letters. Use abc → বাংলা for mixed
  dictation.
- Unconfirmed spellings: star, shah, yeast, costume.

## Install (for builds you make yourself)

- Uninstall any previous Rambler Bangla build first if it was signed with a
  different key.
- Re-enable the keyboard and re-add your layouts after installing.
