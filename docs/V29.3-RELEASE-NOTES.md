# V29.3 release notes (maintainer test build)

## Changes
- Voice typing: English words spoken inside Bangla now come out as proper Bangla transliterations instead of letter-by-letter garble (for example কোম্পানি, টেলিভিশন, বার্লিন). Transliteration only, never translation.
- Multilingual layout: each dictated sentence is all Bangla or all English, never mixed.
- #hashtags and @handles stay in Latin letters on every voice path, so they keep working as tags and mentions.
- "doctor" is written ডক্টর (transliteration) everywhere.
- Typing and paste are unchanged from V29.

## Install
- Uninstall the previous Rambler Bangla first; this build uses a new signing key.
- PixelBoard is not affected.
- Re-enable the keyboard and re-add your layouts after installing.

## Known limits
- Live dictation cannot be tested on an emulator; the final voice check is on a real device.
- Unconfirmed spellings: star, shah, yeast, costume.
- Broader reph / vowel spelling improvements are planned for a later update.
